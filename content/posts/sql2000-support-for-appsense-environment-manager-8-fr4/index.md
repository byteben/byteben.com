If you haven't read the release notes consider this a heads up. If you are planning to install or upgrade your Environment Manager to Version 8 FR4 you will not be surprised that support for SQL 2000 has been removed. If you are still using SQL2000 it is recommended to upgrade your database (compatible versions below) before you attempt an EM upgrade.<!--more-->

_**Microsoft SQL Server 2005 Initial Release up to SP4**_

_**Microsoft SQL Server 2008 _**Initial Release up to**_SP2**_

_**Microsoft SQL Server 2008 R2 _**Initial Release**_**_

_**Microsoft SQL Server 2012 _**Initial Release**_**_

_Environment Manger still supports SQL2000 SP3 only up to version  8.3.239.0 but on _8.3.192.0_ it is only supported for upgrades, not clean installs._

A full compatibility Matrix for support versions can be found at [http://www.MyAppSense.com](<http://www.MyAppSense.com>) > Software > DesktopNow > Environment Manager > EM Compatibility Matrix

Hope this topic helps clear any confusion up.
